# Lane LOG Analyzer

เครื่องมืออ่าน LOG ช่องทางเก็บค่าผ่านทางแบบทำงานในเบราว์เซอร์ ไม่ส่งข้อมูลออกจากเครื่อง

## เปิดใช้งาน

เปิด `index.html` ด้วย Chrome หรือ Edge แล้วเลือกหรือลากไฟล์ `.old`, `.log` หรือ `.txt` ลงในหน้าจอ

## กฎวิเคราะห์ปัจจุบัน

- แบ่ง Passage จาก `PER_GestionDebutPsgPostDac - Debut passage` ถึง `GenererMsgTrx4 ... NumTrx`
- นับขอบขาขึ้น `nv_etat:1` ของ P90 ทั้งสี่จุดและ P45 ทั้งสองจุด
- แจ้งสัญญาณหายหรือจำนวนไม่สมดุลระหว่างเซนเซอร์
- ตรวจทิศทางที่ไม่ใช่ `Sens 1`
- ตรวจ `ERR_*`, `Refus DoubleCycle`, Web API error, timer แบริเออร์ และการ Simulation
- อ่านทะเบียน จังหวัด ด่าน/เวลาเข้า ด่าน/เวลาออก และการชำระจาก `DeductionData`
- แปลลำดับ `C_TOUCHE_*` เพื่อแสดงว่าพนักงานกดปุ่มใดบ้างในแต่ละ Transaction
- ส่งออกผลวิเคราะห์เป็น JSON

ผลวิเคราะห์เป็นตัวช่วยคัดกรองเบื้องต้น ควรยืนยันกับวงจร I/O, คู่มืออุปกรณ์ และการทดสอบหน้างานก่อนเปลี่ยนอะไหล่
